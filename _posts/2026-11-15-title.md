Today I started setting up my personal blog using **GitHub Pages** and **Jekyll** as part of the GitHub Skills exercises.

Instead of dealing with heavy backends or databases, everything runs directly from a Git repository using plain Markdown files. Each post lives inside the `_posts` directory and starts with a YAML front matter block that defines metadata like the title and publication date.

### Key Takeaways So Far

| Concept | Purpose |
| :--- | :--- |
| `_posts/` directory | Stores all blog entries using the `YYYY-MM-DD-title.md` naming convention |
| YAML Front Matter | Configures post-specific metadata at the top of the file |
| Pull Requests | Lets me preview and merge changes cleanly into the live site |

Once this draft is merged, the post will automatically render on the site. I'll expand this space later with notes on software architecture, backend development, and operating systems.
